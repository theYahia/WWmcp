# /payment-link — Ссылка на оплату Payme

## Алгоритм

1. Переведи сумму из сумов в тийины (умножь на 100). Проверь результат вслух перед вызовом.
2. Вызови `receipts_create` с amount в тийинах и account — объект полей заказа,
   например {order_id: "142"}. Ответ содержит id чека.
3. Вызови `receipts_send` с id чека и phone в международном формате без плюса
   (998901234567). Клиент получит SMS со ссылкой и оплатит сам — карта тебе не нужна.
4. Вызови `receipts_check` с id, чтобы увидеть текущее состояние. Сразу после отправки
   чек будет неоплачен — это нормально, повтори проверку позже.
5. Если клиент передумал, вызови `receipts_cancel` с id и reason (числовой код причины).
   Если чек уже оплачен, отмена превращается в возврат — предупреди пользователя об этом
   до вызова.

## Формат ответа

```
## Чек Payme отправлен

**Чек**: 5f8a1c2b3d4e5f6a7b8c9d0e
**Сумма**: 150 000 тийин = 1 500 сум
**Заказ**: order_id 142
**Телефон**: 998901234567
**Статус**: ожидает оплаты

Проверить позже: receipts_check по id чека.
```

## Важно

- amount в тийинах, всегда. 1 500 сум = 150000.
- Телефон без «+» и без пробелов: 998901234567.
- `receipts_cancel` требует числовой reason. Если пользователь не назвал код, спроси —
  не подставляй произвольное число, оно попадает в аудит.
- Поля account зависят от настроек кассы в Payme. Если чек не создаётся, дело обычно
  в несовпадении имени поля (order_id / login / phone) — уточни у пользователя.

## Примеры

```
/payment-link 1500 order-142 998901234567
/payment-link 25000 заказ-991 998935554433
```
