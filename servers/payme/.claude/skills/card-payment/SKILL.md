# /card-payment — Оплата картой в Payme

## Алгоритм

1. Вызови `cards_create` с number (карта серии 8600 — UzCard, 5614 — Humo) и expire
   в формате MMYY. В песочнице используй срок 0399. Ответ содержит token карты.
2. Вызови `cards_verify` с token и code из SMS, который придёт держателю карты.
   В песочнице код всегда 666666. Без этого шага карта не может платить.
3. Вызови `cards_check` с token — убедись, что карта активна, прежде чем списывать.
   Это дешевле, чем ловить ошибку на оплате.
4. Вызови `receipts_create` с amount **в тийинах** (1 сум = 100 тийин, то есть
   100000 = 1000 сум) и account — объект полей заказа, например {order_id: "142"}.
   Ответ содержит id чека.
5. Вызови `receipts_pay` с id чека и token карты.
6. Вызови `receipts_check` с id — подтверди финальный статус чека и время оплаты.

## Формат ответа

```
## Платёж Payme

**Карта**: 8600 **** **** 1234 (UzCard)
**Чек**: 5f8a1c2b3d4e5f6a7b8c9d0e
**Сумма**: 150 000 тийин = 1 500 сум
**Заказ**: order_id 142
**Статус**: оплачен
```

## Важно

- **Суммы везде в тийинах.** Умножай сумы на 100 перед `receipts_create` и дели на 100
  при показе пользователю. Это источник большинства ошибок в 100 раз.
- Токен карты живёт до `cards_remove`. Не создавай новый токен на каждый платёж —
  сохраняй его у себя и переиспользуй.
- По умолчанию сервер стартует в песочнице (PAYME_SANDBOX). Скажи пользователю, в каком
  контуре идёт операция, прежде чем он решит, что деньги реально списались.
- Номер карты и код из SMS — чувствительные данные. Не повторяй их в ответе полностью.

## Примеры

```
/card-payment 8600123456781234 0399 1500 order-142
/card-payment существующий токен 2500 order-143
```
