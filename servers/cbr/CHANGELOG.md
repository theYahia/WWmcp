# Changelog

Все значимые изменения проекта документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект следует [семантическому версионированию](https://semver.org/lang/ru/).

## [1.2.0] — 2026-06-23

### Исправлено
- **Критично: `get_key_rate` был полностью сломан.** Эндпоинт `cbr.ru/scripts/XML_KeyRate.asp`
  больше не существует (отдаёт 302 → 404), SOAP-сервис `DailyInfoWebServ` возвращает пустой ответ.
  Инструмент переписан на парсинг официальной таблицы `cbr.ru/hd_base/KeyRate` и теперь
  возвращает текущую ставку **и дату её вступления в силу**.
- **Таймзона-баг при работе с датами.** Разбор `YYYY-MM-DD` использовал локальные геттеры `Date`
  поверх UTC-полуночи, из-за чего в таймзонах с отрицательным смещением дата уезжала на день
  назад и формировался неверный URL архива. Все операции с датами переведены на UTC.
- **Валидация дат.** Некорректная строка раньше приводила к `NaN` в URL; теперь — понятная ошибка
  с указанием ожидаемого формата.
- **Праздники и выходные.** Запрос курсов на день без публикации (например, 1 января) раньше падал
  с сырым `HTTP 404`; теперь возвращается ближайший доступный рабочий день с пояснением.
- **Деление на ноль** в расчёте `change_percent` (если предыдущий курс равен 0) — теперь `null`.
- Удалён мёртвый код и лишний сетевой вызов в получении ключевой ставки.

### Добавлено
- **`get_rate_dynamics`** — динамика курса валюты за период (`cbr.ru/scripts/XML_dynamic.asp`):
  ряд значений + сводка (min/max/avg, изменение за период).
- **`get_key_rate_history`** — история изменений ключевой ставки за период.
- Драгметаллы теперь возвращают цены покупки и продажи (`buy`/`sell`) вместо единственного значения.
- Отказоустойчивость: при недоступности зеркала `cbr-xml-daily.ru` курсы берутся с официального
  `cbr.ru` (`XML_daily.asp`) с явной пометкой источника.
- Заголовок `User-Agent` во всех запросах к `cbr.ru`.
- Юнит-тесты (vitest) для всех парсеров на офлайн-фикстурах; eslint; CI-матрица Node 18/20/22
  с прогоном тестов в том числе в отрицательной таймзоне.

### Изменено
- Версия сервера теперь читается из `package.json` (раньше была захардкожена и расходилась).
- Ошибки инструментов возвращаются MCP-клиенту как `isError`, а не валят обработчик.
