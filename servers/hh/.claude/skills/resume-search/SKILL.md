# /resume-search — Поиск кандидатов

## Алгоритм

1. **Сначала проверь доступ**: `validate_token` — валиден ли HH_ACCESS_TOKEN и какая у него роль. Поиск по резюме работает только с токеном **работодателя** и оплаченным доступом к базе резюме; соискательский или анонимный токен даст 403.
2. Разреши справочники под фильтры:
   - `suggest_positions` — автодополнение названия должности и роли;
   - `get_professional_roles` — дерево ролей с ID;
   - `suggest_areas` или `get_areas_subtree` — ID региона или города (полное дерево `get_areas` тяжёлое, бери подветку).
3. `search_resumes` — поиск по ключевым словам, региону, профессиональной роли, зарплате, опыту. Разбери выдачу постранично.
4. Открой карточки: `get_resume` — опыт, образование, навыки, контакты.
5. Расшифруй коды опыта, занятости и графика через `get_dictionaries`.
6. Отранжируй кандидатов по релевантности требованиям и покажи короткий список с обоснованием, а не сырой дамп.

## Важно

- Шаг 1 не пропускать. Без него 403 будет выглядеть как «ничего не найдено», и вывод получится ложным.
- Контакты кандидатов — персональные данные: не выгружай их пачками в чат без прямого запроса, работай с короткими списками.
- Резюме в поиске могут быть скрыты или устаревшими; дату обновления показывай всегда.

## Формат ответа

```
## Кандидаты: Python-разработчик, Москва

Доступ: токен работодателя, база резюме — активна
Найдено: 214, показываю топ-5

| Кандидат | Опыт | Ожидания | Обновлено |
|----------|------|----------|-----------|
| id 8f2a… | 6 лет | 280 000 ₽ | 2026-08-30 |

### Почему эти пятеро
1. id 8f2a… — Django + PostgreSQL + Kubernetes, все три требования закрыты.
```

