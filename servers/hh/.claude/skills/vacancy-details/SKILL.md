# /vacancy-details — Разбор вакансии

## Алгоритм

1. Возьми ID вакансии. Если пользователь дал ссылку — ID это число в конце URL. Если дал только название — найди через `search_vacancies` и уточни, какая из них нужна.
2. `get_vacancy` — полное описание: требования, ключевые навыки, условия, контакты, работодатель.
3. Разбери описание на три списка: обязательные требования, желательные, что предлагают. Не пересказывай текст целиком.
4. Расшифруй коды условий (опыт, занятость, график, метки вакансии) через `get_dictionaries`.
5. Уточни географию: `get_metro` — станции и линии по городу, если в вакансии указано метро; `get_areas_subtree` — регион по ID.
6. Расширь воронку: `get_similar_vacancies` — похожие позиции. Это дешевле, чем заново строить поисковый запрос.
7. Сверь зарплату с рынком: `get_professional_roles` для ID роли, затем `get_salary_statistics`.

## Важно

- `get_salary_statistics` — оценка по объявлениям с раскрытой зарплатой, смещённая выборка. Помечай это, не выдавай за официальные данные рынка.
- Контакты в вакансии есть не всегда; отсутствие контактов не ошибка инструмента.
- Отрасль работодателя раскрывается через `get_industries`, в самой вакансии лежит только код.

## Формат ответа

```
## Вакансия 98765432 — Senior Python Developer

**Компания**: Ромашка Технологии · **Регион**: Москва (метро Павелецкая)
**Вилка**: 300 000 — 400 000 ₽ · медиана по роли ~250 000 ₽ (оценка по объявлениям)
**Опыт**: 3-6 лет · Полная занятость · Гибрид

### Обязательно
Python 3, Django, PostgreSQL, Docker

### Желательно
Kubernetes, опыт highload

### Похожие вакансии
1. 98765111 — Python Developer — Москва — 280 000 ₽
```

## Примеры

```
/vacancy-details 98765432
/vacancy-details https://hh.ru/vacancy/98765432
/vacancy-details покажи похожие на 98765432
```
