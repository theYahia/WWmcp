# /employer-research — Досье на работодателя

## Алгоритм

1. Уточни название: `suggest_companies` — автодополнение по частичному вводу, возвращает варианты компаний.
2. `search_employers` — поиск по названию. Возьми из результата employer id и число открытых вакансий.
3. Если совпадений несколько (филиалы, тёзки, кадровые агентства) — покажи список пользователю и дай выбрать, не решай сам.
4. `get_employer` — профиль: описание, отрасли, сайт, количество вакансий.
5. `get_employer_vacancies` — все активные вакансии компании. По ним видно, кого реально нанимают и какие вилки предлагают.
6. Расшифруй коды отраслей через `get_industries` (дерево отраслей с ID).
7. Оцени вилку компании на фоне рынка: `get_professional_roles` — ID роли, затем `get_salary_statistics` по этой роли и региону.

## Важно

- `get_salary_statistics` считает по объявлениям, которые раскрыли зарплату, — это **смещённая выборка**, а не официальные данные рынка. Всегда помечай это в ответе.
- Число вакансий в профиле и в `get_employer_vacancies` может расходиться: профиль кэшируется на стороне hh.
- Кадровые агентства публикуют вакансии клиентов — по ним нельзя судить о найме самого агентства.

## Формат ответа

```
## Компания: Ромашка Технологии (id 1234567)

**Отрасли**: Информационные технологии, Разработка ПО
**Сайт**: romashka.ru
**Открытых вакансий**: 18

### Кого нанимают
| Вакансия | Регион | Вилка |
|----------|--------|-------|
| Python-разработчик | Москва | 250 000 — 350 000 ₽ |
| DevOps-инженер | Удалённо | 280 000 ₽ |

**Вилка компании vs рынок**: медиана по роли ~250 000 ₽ (оценка по объявлениям с указанной зарплатой, не официальная статистика).
```

## Примеры

```
/employer-research Ромашка
/employer-research Яндекс
/employer-research кто нанимает питонистов в Казани
```
