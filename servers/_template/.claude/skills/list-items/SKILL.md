# /list-items — список элементов CHANGEME

Скилл-заготовка. Оставь его форму, замени содержимое под свой API: скилл — это то, как
агент пользуется сервером, а не пересказ README. Проверка `packages/core/tests/skills-consistency.test.ts`
следит, чтобы каждое имя инструмента в обратных кавычках существовало у сервера, а в
`allowed-tools` стоял хотя бы один `mcp__`.

## Algorithm

1. Если пользователь не назвал, что ищет — покажи первую страницу без фильтра.
2. Вызови `list_items` с `query` из запроса пользователя и `limit` (по умолчанию 20, максимум 100).
3. Формат ответа: `concise` для списка, `detailed` — только если пользователь спросил про
   конкретный элемент и нужны все поля.
4. Если вернулось пусто — скажи об этом прямо и предложи ослабить фильтр, не повторяй тот же
   запрос второй раз.
5. Если в ответе стоит «Показано N из M» — не тяни остальные страницы молча: спроси, нужны ли они.

## Response format

```
## Элементы CHANGEME — «<запрос>»

| # | ID | Название | Статус |
|---|----|----------|--------|
| 1 | 1001 | Первый | активен |

Показано 20 из 137.
```

## Notes

- `limit` жёстко ограничен диапазоном 1..100 — большего API не отдаст за один запрос.
- Ошибка приходит текстом с пометкой, что делать дальше; следуй ей, а не повторяй вызов вслепую.

## Examples

```
/list-items
/list-items накладные 50
```
