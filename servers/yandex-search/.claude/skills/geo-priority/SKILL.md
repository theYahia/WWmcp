# /geo-priority — Региональный срез спроса

## Алгоритм

1. Вызови `wordstat_regions` с phrase, top (1–30, по умолчанию 10) и sort_by = volume —
   получишь регионы с наибольшим абсолютным объёмом.
2. Вызови `wordstat_regions` ещё раз с той же фразой и sort_by = affinity — получишь
   регионы, где интерес выше среднего по стране. Это разные списки, и разница как раз
   и есть полезный сигнал.
3. Объясни разницу пользователю: volume показывает, где людей просто больше (Москва и
   Питер почти всегда сверху); affinity > 100 показывает, где к теме относятся
   непропорционально теплее относительно населения региона.
4. Собери две группы:
   - **Объёмные** — куда идти за масштабом.
   - **Недооценённые** — высокий affinity при среднем объёме: там дешевле клик и меньше
     конкуренции.
5. Если пользователь выбирает между регионами для запуска — сравни их в одной таблице
   и назови рекомендацию с числами, а не «попробуйте оба».

## Формат ответа

```
## Регионы: «доставка цветов»

### По объёму
| Регион | Объём/мес | Affinity |
|--------|-----------|----------|
| Москва | 40 200 | 118 |
| Санкт-Петербург | 14 100 | 106 |

### По affinity (недооценённые)
| Регион | Объём/мес | Affinity |
|--------|-----------|----------|
| Краснодарский край | 5 400 | 172 |
| Калининградская обл. | 900 | 164 |

**Вывод**: масштаб — Москва; дешёвый старт — Краснодарский край
(affinity 172 при объёме 5 400).
```

## Важно

- Affinity 100 = средний интерес по стране. Ниже 100 — тема в регионе холоднее среднего.
- Малый регион с высоким affinity может давать десятки запросов в месяц — смотри объём
  вместе с индексом, иначе получится рекомендация в пустоту.
- top максимум 30 регионов за вызов.

## Примеры

```
/geo-priority доставка цветов
/geo-priority "кухни на заказ" 20
```
