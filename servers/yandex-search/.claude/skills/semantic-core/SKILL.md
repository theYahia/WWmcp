# /semantic-core — Семантическое ядро из Wordstat

## Алгоритм

1. Составь список seed-фраз из запроса пользователя. Если он дал одну — придумай ещё 2-3
   синонима и покажи их ему на подтверждение, прежде чем тратить квоту.
2. По каждой seed-фразе вызови `wordstat_top_requests` с phrase и limit (1–50,
   по умолчанию 20). Ответ — связанные запросы с месячным объёмом.
3. Сведи все выдачи в один список, убери дубли, отсортируй по объёму.
4. Разбей на кластеры по смыслу: коммерческие («купить», «цена», «заказать»),
   информационные («как», «что такое», «отзывы»), брендовые.
5. Для фраз с объёмом выше 10 000/мес вызови `wordstat_dynamics` с phrase, from_year
   и to_year — получишь помесячный тренд и увидишь сезонность. Для низкочастотников
   этот инструмент не работает: он вернёт пустоту, а не ошибку. Не пытайся.
6. Отдай ядро таблицей: фраза, объём, кластер, интент, сезонный пик.

## Формат ответа

```
## Семантическое ядро: «доставка цветов»

Всего собрано: 87 фраз, суммарный объём 214 300/мес

### Коммерческие (топ)
| Фраза | Объём/мес | Сезонный пик |
|-------|-----------|--------------|
| доставка цветов москва | 40 200 | март (8×) |
| заказать цветы с доставкой | 18 400 | март |

### Информационные
| как выбрать букет | 3 100 | — |

**Сезонность ядра**: пик 6-8 марта, провал июль-август.
```

## Важно

- `wordstat_dynamics` работает только для высокочастотных фраз (>10 000 запросов/мес).
  Для остальных — только `wordstat_top_requests`.
- Объёмы Wordstat — это показы, а не переходы. Не выдавай их за трафик.
- Каждый вызов расходует квоту Yandex Cloud Search API. Не гоняй все 87 фраз через
  `wordstat_dynamics` — только те, что реально несут бюджет.

## Примеры

```
/semantic-core доставка цветов
/semantic-core "мебель на заказ", "кухни на заказ"
```
