# /vacancy-funnel — Воронка вакансии

## Алгоритм

1. `list_accounts` — если account_id не задан, возьми его отсюда.
2. `list_vacancies` (account_id, opened, state, mine, count, page) — найди нужную вакансию и её ID.
3. `get_vacancy` (account_id, vacancy_id) — карточка: название, дата создания, подразделение. Посчитай, сколько дней вакансия открыта.
4. `list_stages` (account_id) — этапы воронки. **Обязательный шаг**: у кандидатов лежат числовые status, без справочника воронка не читается.
5. `list_vacancy_applicants` (account_id, vacancy_id, status, count, page) — кандидаты вакансии. Пройди все страницы и разложи по этапам.
6. Посчитай конверсию: сколько дошло с первого этапа до финального, где самая большая просадка.
7. Разбери отказы: `list_rejection_reasons` (account_id) — расшифровка причин.
8. Достройте контекст: `list_coworkers` (account_id, count, page) — кто из рекрутеров ведёт вакансию; `list_divisions` (account_id) — подразделение; `list_sources` (account_id) — откуда идут кандидаты.

## Важно

- Не заявляй итог по воронке, пока не прошёл все страницы `list_vacancy_applicants`: обрезанная выборка даёт ложную конверсию. Указывай, сколько кандидатов реально выгрузил.
- Кандидат может быть прикреплён к нескольким вакансиям — числа по вакансиям не складываются в «всего кандидатов в аккаунте».
- Сервер только читает: двигать кандидата по этапам и оформлять отказ нужно в HuntFlow.

