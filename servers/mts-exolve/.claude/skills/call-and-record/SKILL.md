# /call-and-record — Звонок и запись

## Алгоритм

1. Определи номер, с которого звоним. Если пользователь не назвал — вызови `list_numbers`
   (параметров нет) и покажи купленные номера аккаунта.
2. Вызови `make_call` с from (номер звонящего) и to (номер вызываемого абонента).
   Ответ содержит call_id — сохрани его, без него ни статус, ни запись не получить.
3. Вызови `get_call_status` с call_id. Сразу после инициации звонок будет в промежуточном
   состоянии — это нормально, повтори проверку через несколько секунд.
4. Когда статус финальный, вызови `get_call_recording` с call_id — вернётся ссылка на
   аудиофайл и длительность.
5. Если запись ещё не готова, инструмент вернёт пусто. Подожди и повтори один раз,
   прежде чем сказать, что записи нет — не объявляй её отсутствующей с первой попытки.
6. Отчитайся: состоялся ли разговор, сколько длился, есть ли запись.

## Формат ответа

```
## Звонок MTS Exolve

**От**: 79001234567
**Кому**: 79121234567
**call_id**: c8f2a91c-0b44-4e1a-9d2f-771002abcd10
**Статус**: завершён
**Длительность**: 3 мин 42 с

**Запись**: https://api.exolve.ru/... (2:58)
```

## Важно

- `make_call` инициирует реальный звонок. Не вызывай его для проверки конфигурации.
- Номера в формате 7XXXXXXXXXX — без плюса и без восьмёрки.
- Звонок с номера, не принадлежащего аккаунту, будет отклонён. Сверяйся с `list_numbers`.
- Записи разговоров — персональные данные. Ссылку отдавай пользователю, содержимое
  не пересказывай без запроса.
- Если нужен новый номер под направление, вызови `buy_number` с region
  (например moscow, spb) и type (mobile, local, tollfree).

## Примеры

```
/call-and-record 79001234567 79121234567
/call-and-record 79121234567
```
