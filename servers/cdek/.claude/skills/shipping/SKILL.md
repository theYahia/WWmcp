# /shipping — Доставка через СДЭК

## Алгоритм

1. Вызови `get_cities`, чтобы найти `city_code` городов отправления и назначения
2. Вызови `calculate_tariff` с тарифом 136 (склад-склад) для расчёта стоимости — вес передаётся **в граммах** (умножь килограммы на 1000)
3. Вызови `list_delivery_points` для обоих городов, чтобы показать ближайшие ПВЗ (можно добавить `latitude`/`longitude`/`radius_km` для поиска по координатам)
4. Покажи результат: стоимость, сроки, ПВЗ

## Примеры

    /shipping Москва Казань 2
    /shipping Новосибирск Екатеринбург 5
