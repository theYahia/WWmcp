# /convert — Конвертация валюты

## Алгоритм

1. Получи сумму, исходную валюту и целевую валюту
2. Вызови `convert_currency` с параметрами amount, from, to
3. Покажи результат конвертации с использованным курсом

## Формат ответа

```
## Конвертация по курсу ЦБУ

**1 000 USD** → **12 750 000 UZS**
**Курс**: 1 USD = 12 750.00 UZS
**Дата курса**: 31.03.2026
```

## Примеры

```
/convert 1000 USD UZS
/convert 5000000 UZS EUR
/convert 100 EUR RUB
```
