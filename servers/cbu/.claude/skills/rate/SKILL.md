# /rate — Курс валюты ЦБУ

## Алгоритм

1. Получи код валюты (USD, EUR, RUB и т.д.) и опциональную дату
2. Вызови `get_currency_rate` с `currency_code` (и `date`, если дата указана)
3. Если валюта не указана — `get_all_rates` и покажи весь список
4. Покажи курс в компактном формате

## Формат ответа

```
## Курс ЦБУ на 31.03.2026

**USD/UZS**: 12 750.00
**Изменение**: +15.00
```

## Примеры

```
/rate USD
/rate EUR 2026-03-15
/rate RUB
```
