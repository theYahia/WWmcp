# /gigachat-image — Картинка из текста

## Алгоритм

1. Вызови `get_balance` — проверь остаток токенов и квоты. Генерация изображений съедает
   заметно больше, чем текст; узнать об исчерпании до вызова дешевле, чем после.
2. Собери промпт. GigaChat генерирует изображение из обычного сообщения диалога,
   поэтому опиши картинку прямо в тексте: сюжет, стиль, композиция, палитра.
3. Вызови `generate_image` с model (GigaChat или GigaChat-Pro) и messages — массивом
   объектов вида роль user плюс content с описанием.
4. Ответ содержит идентификатор файла изображения. Отдай его пользователю и скажи, как
   картинку забрать — прямой ссылки в ответе нет.
5. Если результат не устроил, уточняй промпт по одному параметру за итерацию (сначала
   сюжет, потом стиль, потом палитра) — так видно, что именно повлияло.
6. Если нужно приложить референс, вызови `file_upload` с file_content (base64),
   file_name и purpose, и упомяни файл в сообщении.

## Формат ответа

```
## Изображение GigaChat

**Модель**: GigaChat-Pro
**Промпт**: «Осенний парк в тумане, акварель, приглушённая палитра»
**Файл**: img_8f2a91c0
**Квота**: осталось 128 400 токенов

Уточнить: добавьте в промпт время суток и ракурс.
```

## Важно

- В отличие от текстовой генерации, у `generate_image` нет параметров temperature
  и max_tokens — вся настройка идёт через формулировку промпта.
- Ответ отдаёт идентификатор файла, а не картинку в ответе. Не утверждай, что
  показал изображение.
- GigaChat отклоняет промпты, нарушающие его политику контента. Ошибку показывай как есть,
  не обходи её переформулировками без запроса пользователя.

## Примеры

```
/gigachat-image осенний парк в тумане, акварель
/gigachat-image логотип кофейни, минимализм, две краски GigaChat-Pro
```
