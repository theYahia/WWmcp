# /my-listings — Мои объявления Avito

## Алгоритм

1. Вызови `list_my_items`. Параметры: page (с 1), per_page (1–100, по умолчанию 25),
   status (active | old | blocked | rejected | removed), category (числовой ID категории Avito).
2. Если пользователь не назвал статус — покажи все и сгруппируй по статусам сам.
3. Если объявлений больше одной страницы — пройди страницы через page, пока не наберёшь
   всё или пока пользователь не остановит. Не выдумывай общее число, если не дошёл до конца.
4. Для каждого проблемного объявления (blocked, rejected) вызови `get_item_info` по item_id —
   там статус, применённые платные услуги и базовая статистика показов/контактов.
5. Сведи в таблицу и отдельно выдели то, что требует действий.

## Формат ответа

```
## Объявления Avito

| Статус | Количество |
|--------|-----------|
| active | 42 |
| blocked | 3 |
| rejected | 1 |

### Требуют внимания
1. id 3721885012 — «Диван угловой» — rejected
2. id 3721885120 — «Стол дубовый» — blocked

### Активные (топ по просмотрам)
1. id 3721884001 — «Кресло IKEA» — 1 240 просмотров, 18 контактов
```

## Важно

- user_id берётся из переменной окружения AVITO_USER_ID, если не передан явно — не спрашивай
  его у пользователя без необходимости.
- category — это числовой ID категории Avito, а не название. Если пользователь назвал
  категорию словами, фильтруй результат `list_my_items` на своей стороне.
- В версии 0.1.0 сервера нет инструментов редактирования объявлений — только чтение.
  Если пользователь просит изменить цену или текст, скажи об этом прямо.

## Примеры

```
/my-listings
/my-listings active
/my-listings blocked
```
