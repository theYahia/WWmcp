# /inbox-triage — Чаты Avito

## Алгоритм

1. Вызови `list_chats` с unread_only = true, чтобы получить только чаты с непрочитанными
   сообщениями. Параметры: limit (1–100, по умолчанию 50), offset для пагинации,
   item_ids — массив ID объявлений, если нужны чаты по конкретным лотам.
2. Собери из ответа список item_id, по которым идёт переписка.
3. Для каждого такого объявления вызови `get_item_info` — нужно название и статус,
   чтобы понимать, о чём спрашивают и активно ли ещё объявление.
4. Отметь отдельно чаты по объявлениям, которые уже неактивны (old, removed) —
   на них обычно отвечают в первую очередь, чтобы закрыть вопрос.
5. Если пользователь просит полный список — повтори `list_chats` без unread_only,
   листая через offset.

## Формат ответа

```
## Чаты Avito — непрочитанные

Всего непрочитанных чатов: 7

| # | Объявление | Статус объявления | Непрочитано |
|---|-----------|-------------------|-------------|
| 1 | Кресло IKEA (3721884001) | active | 2 |
| 2 | Стол дубовый (3721885120) | removed | 1 |

### Срочно
- «Стол дубовый» — объявление снято, а вопрос висит.
```

## Важно

- В версии 0.1.0 сервера **нет** инструментов отправки сообщений и отметки «прочитано» —
  только просмотр списка чатов. Если пользователь просит ответить в чате, скажи, что это
  надо сделать в приложении Avito.
- Тексты сообщений `list_chats` тоже не отдаёт — только метаданные чатов. Не пересказывай
  содержимое переписки, которого не видел.
- user_id подставляется из AVITO_USER_ID, если не передан.

## Примеры

```
/inbox-triage
/inbox-triage только непрочитанные
/inbox-triage по объявлению 3721884001
```
