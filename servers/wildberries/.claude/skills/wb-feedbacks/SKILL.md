# /wb-feedbacks — Отзывы, вопросы, возвраты

## Алгоритм — отзывы

1. `get_feedbacks` с isAnswered=false, take (сколько взять), skip, order (dateAsc / dateDesc) — неотвеченные отзывы.
2. Сгруппируй по товару и по оценке; выдели повторяющиеся claims (брак, размер, комплектация).
3. Для каждого отзыва подготовь текст ответа и **покажи его пользователю на подтверждение**.
4. После подтверждения — `reply_feedback` с id отзыва и text.

## Алгоритм — вопросы

1. `get_questions` с isAnswered=false, take, skip, order — неотвеченные вопросы покупателей.
2. Если для ответа нужны характеристики товара — подтяни их через `get_product` с nmIDs.
3. Подготовь ответ, покажи пользователю, затем `reply_question` с id и text (параметр state оставляй по умолчанию, если пользователь не просил иного).

## Алгоритм — возвраты

1. `get_returns` с isArchive=false, limit (до 200), offset, nmId — активные заявки на возврат.
2. Сопоставь причины возвратов с текстами отзывов из шага «отзывы»: совпадающая причина = проблема карточки или качества, а не покупателя.

## Важно

- Ответы публичные и необратимые — **никогда не отправляй `reply_feedback` / `reply_question` без явного согласия пользователя на конкретный текст**.
- Отвечай по существу претензии, без шаблонных извинений; на 1-2 звезды — что именно исправлено.
- Отзывы и вопросы — разные ленты: неотвеченный вопрос через `get_feedbacks` не найдётся.

## Формат ответа

```
## Отзывы Wildberries

Неотвеченных: 12 (из них 1-2★: 4)

### Повторяющиеся претензии
1. «Размер меньше» — 5 отзывов — Футболка базовая (nmID 123456789)
2. «Пришло без коробки» — 3 отзыва

### Черновики ответов
1. Отзыв abc123 (2★, «размер меньше») → «...»  [ждёт подтверждения]

### Возвраты
Активных заявок: 3 — причина «не подошёл размер» ×2
```

## Примеры

```
/wb-feedbacks отзывы
/wb-feedbacks вопросы
/wb-feedbacks возвраты по 123456789
```
