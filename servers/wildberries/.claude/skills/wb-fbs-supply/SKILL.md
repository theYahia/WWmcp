# /wb-fbs-supply — Остатки и поставки FBS

## Алгоритм — проверка остатков

1. Вызови `get_warehouses` — получи ID своих складов (нужен warehouseId для всех операций со стоком).
2. Вызови `get_stocks` с warehouseId (и skus, если интересуют конкретные баркоды) — текущие остатки FBS.
3. Если нужно поправить остатки — `update_stocks` с warehouseId и массивом stocks (sku + amount).
4. Для товаров на складах WB (FBW) сток другой: `get_fbw_stocks` с dateFrom, приёмки — `get_incomes`.

## Алгоритм — сборка поставки

1. `get_new_orders` — новые несобранные заказы FBS (без параметров). Для выборки за период — `get_orders` с dateFrom / dateTo.
2. `create_supply` с name — создай поставку, запомни supplyId из ответа (формат WB-GI-1234567).
3. `add_orders_to_supply` с supplyId и orderIds — прикрепи сборочные задания.
4. `deliver_supply` с supplyId — закрой поставку и отправь в доставку. После этого заказы уходят в статус «в доставке».
5. `get_supply_barcode` с supplyId — QR-код поставки (type: svg / zpl / png). Доступен только после `deliver_supply`.
6. Список поставок и их статусы — `get_supply`.

## Важно

- Порядок шагов 2→3→4 обязателен: закрытая поставка новых заказов не принимает.
- `update_stocks` пишет остатки только для FBS-склада продавца. Остатки FBW правятся поставкой на склад WB, не этим инструментом.
- sku в `get_stocks` / `update_stocks` — это баркод, не nmID.

## Формат ответа

```
## FBS Wildberries

### Остатки (склад 1234567)
| SKU | Остаток |
|-----|---------|
| 2037554123456 | 12 |

### Поставка WB-GI-1234567
Заказов прикреплено: 14
Статус: отправлена в доставку
QR: получен (svg)
```

## Примеры

```
/wb-fbs-supply остатки
/wb-fbs-supply собери поставку из новых заказов
/wb-fbs-supply обнови остаток 2037554123456 на 30
```
