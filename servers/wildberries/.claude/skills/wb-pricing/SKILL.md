# /wb-pricing — Цены и юнит-экономика

## Алгоритм

1. Найди карточки: `list_products` (limit, textSearch, cursor для следующей страницы) — из ответа возьми nmID.
2. Для точных данных по конкретным карточкам — `get_product` с массивом nmIDs (до 100).
3. Перед изменением цены проверь издержки:
   - `get_commission` — комиссия WB по категории (locale: ru / en / zh);
   - `get_tariffs` — тарифы логистики и хранения на дату (date, по умолчанию сегодня);
   - `get_paid_storage` с dateFrom / dateTo — фактическая стоимость платного хранения за период.
4. Посчитай, что остаётся продавцу: цена − комиссия − логистика − хранение.
5. Примени новые цены через `update_prices` с массивом prices (nmID + price в рублях).
6. Проверь эффект: `get_abc_analysis` с dateFrom / dateTo — попал ли товар в группу A по выручке.

## Важно

- `update_prices` создаёт **асинхронную** задачу загрузки: ответ приходит сразу, цены применяются с задержкой. Перечитай `get_product`, чтобы убедиться.
- price передаётся целым числом в рублях, копейки не поддерживаются.
- Скидка на WB задаётся в кабинете отдельно от цены; этот сервер меняет базовую цену, поэтому итоговую цену покупателя всегда сверяй с карточкой после применения.
- Никогда не меняй цену пачкой, не показав пользователю расчёт по шагу 4.

## Формат ответа

```
## Цены Wildberries

| nmID | Товар | Было | Стало | Комиссия | Логистика | Остаётся |
|------|-------|------|-------|----------|-----------|----------|
| 123456789 | Кружка синяя | 890 ₽ | 990 ₽ | 17% | 55 ₽ | 767 ₽ |

Задача на обновление цен отправлена: 3 позиции.
```

## Примеры

```
/wb-pricing кружка
/wb-pricing 123456789 990
/wb-pricing проверь комиссию и логистику по категории
```
