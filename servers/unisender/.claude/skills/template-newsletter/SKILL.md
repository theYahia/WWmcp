# /template-newsletter — Письмо из шаблона и отчёт

## Алгоритм

1. Вызови `get_templates` с type (user — свои шаблоны, system — системные), limit
   и offset. Найди нужный шаблон и возьми его ID.
2. Вызови `get_template` с template_id — получи тему и HTML-тело. Покажи пользователю
   тему и краткое описание содержимого перед отправкой.
3. Вызови `get_lists` и подтверди список получателей: название и ID. Ошибиться списком
   дороже, чем ошибиться текстом — отправку не отменить.
4. Вызови `create_email` с sender_name, sender_email, subject, body (HTML из шаблона)
   и list_id. Ответ содержит message_id.
5. Покажи пользователю финальную сводку — отправитель, тема, список, число получателей —
   и получи явное подтверждение.
6. Вызови `send_email` с message_id. Ответ содержит campaign_id.
7. Вызови `get_campaign_status` с campaign_id — отправлено, доставлено, открыто, клики.
   Для детального разбора вызови `get_campaign_delivery_stats` с campaign_id и опционально
   changed_since (формат YYYY-MM-DD HH:MM:SS) — там отказы и отписки поадресно.

## Формат ответа

```
## Рассылка UniSender

**Шаблон**: «Осенняя акция» (template_id 8812)
**Тема**: Скидки до 40% до 15 октября
**Список**: «Клиенты сентябрь» (4471), 330 контактов
**campaign_id**: 99182

| Метрика | Значение |
|---------|----------|
| отправлено | 330 |
| доставлено | 318 (96,4%) |
| открыто | 92 (28,9%) |
| клики | 24 (7,5%) |
| отписки | 3 |
| отказы (bounce) | 12 |
```

## Важно

- Между `create_email` и `send_email` есть точка невозврата. Подтверждение у пользователя
  запрашивай именно там, а не после.
- Статистика набирается часами. Открытия, снятые через минуту после отправки, ничего не
  значат — скажи пользователю, когда возвращаться за цифрами.
- Высокий bounce (больше 5%) означает грязную базу и бьёт по репутации домена.
  Вынеси это в вывод, если увидел.
- `send_email` берёт message_id из `create_email`, а `get_campaign_status` — campaign_id
  из `send_email`. Это разные идентификаторы, не путай их.

## Примеры

```
/template-newsletter 8812 4471
/template-newsletter "Осенняя акция" в список Клиенты сентябрь
```
