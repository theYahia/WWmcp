# /assign-task — Поставить задачу

## Алгоритм

1. Уточни у пользователя: название задачи, исполнитель, проект, срок.
2. Найди ID исполнителя: `list_users` (offset, pageSize, fields). Имя в Planfix не заменяет ID — `create_task` принимает только числовой assigneeId.
3. Найди ID проекта: `get_projects` (offset, pageSize, fields), при необходимости карточка проекта — `get_project` (projectId).
4. Если проект использует кастомные поля, посмотри их состав: `list_custom_fields` (objectType).
5. Покажи пользователю собранную карточку задачи (кто, что, куда, когда) и **дождись подтверждения**.
6. Создай задачу: `create_task` (name, description, projectId, assigneeId, priority). Из ответа возьми ID задачи.
7. Проверь результат: `get_task` (taskId, fields).
8. Если нужен вводный контекст для исполнителя — `add_comment` (taskId, body).

## Важно

- Совпадение по имени в `list_users` может быть неоднозначным (однофамильцы) — покажи кандидатов пользователю, не выбирай сам.
- Значения priority в API не верифицированы против живого стенда: если пользователь не назвал приоритет явно, поле не передавай.
- Файл к задаче добавляется отдельно: `upload_file_from_url` (url, name), метаданные — `get_file` (fileId).

## Формат ответа

```
## Задача создана

**ID**: 15420
**Название**: Подготовить отчёт по Q3
**Исполнитель**: Иванов И. (userId 331)
**Проект**: Финансы 2026 (projectId 88)
**Комментарий**: добавлен

Ссылка на задачу — в кабинете Planfix.
```

## Примеры

```
/assign-task "Подготовить отчёт по Q3" Иванов
/assign-task "Проверить договор" Петров Финансы
/assign-task покажи сотрудников
```
