# Changelog

Все значимые изменения `@theyahia/bitrix24-mcp` документируются здесь.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект следует [семантическому версионированию](https://semver.org/lang/ru/).

Даты — даты публикации в npm.

## [1.2.0] — 2026-05-03

Первая публикация из монорепозитория WWmcp. В npm это текущая версия (`dist-tag latest`),
хотя формально она младше опубликованных ранее 3.0.x из отдельного репозитория.

### Added

- 4 инструмента: `get_deals`, `create_deal`, `get_contacts`, `create_task`.
  Авторизация — через путь входящего вебхука.
- Сервер собран на `@theyahia/mcp-core`: `BaseHttpClient`, `runServer`
  (stdio + Streamable HTTP), `withErrorHandling`, `createLogger`.
