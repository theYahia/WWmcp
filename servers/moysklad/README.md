# MCP-сервер для МойСклад — товары, остатки, заказы и отчёт по прибыли (10 инструментов)

Позволяет спросить у ассистента, сколько товара осталось на складе, найти позицию по артикулу, поменять цену, завести заказ покупателя или приёмку от поставщика и посмотреть прибыль с маржой по каждому товару за период. Цены во всех инструментах — в рублях: перевод в копейки, которых требует API МойСклад, сервер делает сам. Лимит запросов МойСклада соблюдается автоматически (token bucket 45 запросов за 3 секунды).

## Установка

### Claude Desktop

`claude_desktop_config.json` — macOS: `~/Library/Application Support/Claude/`, Windows: `%APPDATA%\Claude\`.

```json
{
  "mcpServers": {
    "moysklad": {
      "command": "npx",
      "args": ["-y", "@theyahia/moysklad-mcp"],
      "env": {
        "MOYSKLAD_TOKEN": "your-api-token"
      }
    }
  }
}
```

Вместо токена можно передать логин и пароль:

```json
"env": {
  "MOYSKLAD_LOGIN": "user@company",
  "MOYSKLAD_PASSWORD": "your-password"
}
```

### Claude Code

```bash
claude mcp add moysklad \
  -e MOYSKLAD_TOKEN=your-api-token \
  -- npx -y @theyahia/moysklad-mcp
```

### VS Code / Cursor

```json
{
  "servers": {
    "moysklad": {
      "command": "npx",
      "args": ["-y", "@theyahia/moysklad-mcp"],
      "env": {
        "MOYSKLAD_TOKEN": "your-api-token"
      }
    }
  }
}
```

Требуется Node.js 18 или новее.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `search_products` | Поиск товаров по названию или артикулу. Постраничный список с ценами продажи и закупки в рублях, до 1000 записей на страницу. `filter_article` — точное совпадение по SKU |
| `get_product` | Товар по UUID целиком: название, артикул, код, описание, цены продажи и закупки в рублях, вес, объём, время последнего изменения |
| `create_product` | Создаёт товар: название, артикул, описание, код, цены в рублях, вес в граммах, объём в литрах, ставка НДС. Возвращает созданный товар с присвоенным UUID |
| `update_prices` | Меняет цену продажи, закупки или минимальную цену у товара по UUID. Цены в рублях; метаданные типа цены при обновлении сохраняются |
| `get_stock` | Отчёт по остаткам: количество, резерв и ожидание по каждой позиции. Группировка по товару, модификации или складу; фильтр по уровню остатка (положительный, отрицательный, нулевой, ненулевой) |
| `get_counterparties` | Поиск контрагентов — покупателей и поставщиков — по названию или ИНН. Возвращает id, название, телефон, email, ИНН и тип компании. `filter_inn` — точное совпадение по ИНН |
| `create_customer_order` | Создаёт заказ покупателя. Нужны meta-ссылки организации и контрагента и хотя бы одна позиция с товаром и количеством. Поддерживает скидку по позиции |
| `get_orders` | Заказы покупателей с поиском по названию или номеру, фильтром по статусу и контрагенту, сортировкой по дате создания, дате документа или сумме. Суммы в рублях |
| `get_profit_report` | Прибыль по товарам: продано штук и на сумму, себестоимость, возвраты, прибыль и маржа. Период задаётся `moment_from` / `moment_to` в ISO 8601 |
| `create_supply` | Оформляет приёмку товара от поставщика на склад. Нужны meta-ссылки организации и контрагента и позиции с товарами; опционально склад, входящий номер и дата |

## Примеры запросов

- «Каких товаров осталось меньше пяти штук на основном складе — покажи с артикулами».
- «Найди контрагента по ИНН 7707083893 и посмотри его заказы за последний квартал».
- «Посчитай прибыль и маржу по товарам за июнь — какие пять позиций принесли больше всего».

## Переменные окружения

Авторизация двойная: либо токен, либо пара логин + пароль.

| Переменная | Обязательна | Где взять |
|---|---|---|
| `MOYSKLAD_TOKEN` | да, если не заданы логин и пароль | Токен доступа к API МойСклад |
| `MOYSKLAD_LOGIN` | да, если не задан токен | Логин пользователя МойСклад |
| `MOYSKLAD_PASSWORD` | да, если не задан токен | Пароль того же пользователя |

Токен имеет приоритет: если он задан, логин и пароль не используются.

## Транспорт

По умолчанию сервер работает через stdio — этого достаточно для Claude Desktop, Claude Code, VS Code и Cursor.

Для запуска по HTTP (Streamable HTTP, эндпоинт `/mcp` плюс `/health` со статусом и числом инструментов) передайте флаг `--http` или задайте `HTTP_PORT`:

```bash
HTTP_PORT=3000 npx -y @theyahia/moysklad-mcp
```
