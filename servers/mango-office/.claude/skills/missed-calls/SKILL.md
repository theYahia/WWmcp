# /missed-calls — Пропущенные звонки

## Алгоритм

1. Если пользователь просит «за сегодня» — вызови `skill_call_history`, это готовый отчёт
   по звонкам за текущий день, без параметров.
2. Для произвольного периода вызови `get_calls` с date_from и date_to (UNIX timestamp
   или ISO 8601) и limit (1–1000, по умолчанию 100).
3. Отфильтруй записи с незавершённым разговором: пропущенные и сброшенные до ответа.
   Сгруппируй по номеру звонившего — повторные попытки одного клиента считай одним лидом.
4. Вызови `get_users` с limit, чтобы сопоставить внутренние номера с именами сотрудников
   и увидеть, на ком именно копятся пропуски.
5. Вызови `skill_stats` для сводки за сегодня или `get_stats` с date_from и date_to
   за период — процент пропущенных относительно всего трафика.
6. Отсортируй список для обзвона: сверху те, кто звонил больше одного раза.

## Формат ответа

```
## Пропущенные звонки — 01.09 — 03.09

**Всего звонков**: 412
**Пропущено**: 47 (11,4%)
**Уникальных номеров**: 39

### Перезвонить в первую очередь
| Номер | Попыток | Последняя | Линия |
|-------|---------|-----------|-------|
| +7912... | 3 | 03.09 14:22 | Отдел продаж |

### По сотрудникам
| Сотрудник | Внутр. | Пропущено |
|-----------|--------|-----------|
| Иванов И. | 101 | 18 |
```

## Важно

- date_from и date_to принимают UNIX timestamp или ISO 8601. Если пользователь сказал
  «за неделю» — посчитай границы сам и назови их в ответе, чтобы он проверил.
- limit по умолчанию 100. За загруженный день этого мало — подними до 1000, иначе
  процент пропущенных будет посчитан по обрезанной выборке.
- Номера клиентов — персональные данные. Не выгружай полный список без запроса.

## Примеры

```
/missed-calls за сегодня
/missed-calls 2026-09-01 2026-09-03
```
