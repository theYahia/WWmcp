# /check-wall

## Алгоритм
1. Если передано короткое имя, а не числовой ID — узнай ID через `get_groups` (сообщество) или `get_user` (пользователь). Для стены сообщества `owner_id` отрицательный.
2. Вызови `get_wall` с этим `owner_id`.
3. Если нужен поиск по ключевым словам по всей ленте — вызови `search_posts`.
4. Покажи результат в читаемом формате: дата, текст, лайки, репосты, просмотры.

## Примеры
```
/check-wall <id группы или пользователя>
```
