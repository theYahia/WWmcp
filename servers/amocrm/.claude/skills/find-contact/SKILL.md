# /find-contact — Найти или завести контакт

## Алгоритм

1. `search` (query — минимум 3 символа, limit до 250) — сквозной поиск по сделкам, контактам и компаниям. Первый шаг всегда он: он единственный ищет сразу по трём сущностям.
2. Уточни точечно, если сквозной поиск дал шум:
   - `list_contacts` (query, page, limit, with) — по имени, телефону, email;
   - `list_companies` (query, page, limit, with) — по названию компании.
3. Открой карточку: `get_contact` (contact_id, with) — включая кастомные поля с телефоном и почтой.
4. **Проверка дубля обязательна перед созданием.** Один и тот же телефон в двух карточках ломает всю последующую аналитику. Нашёл совпадение — покажи его и спроси, создавать ли новое.
5. Создание контакта: `create_contact` (name или first_name + last_name, responsible_user_id, custom_fields_values — сюда кладутся телефон и email).
6. Создание компании: `create_company` (name, responsible_user_id, custom_fields_values — адрес, сайт).
7. Зафиксируй, откуда контакт: `add_note` (entity_id, entity_type: contacts, note_type, text).
8. Что по нему уже происходило — `list_events` (entity: contacts, entity_id, page, limit) и связанные сделки через `list_leads` (query).

## Важно

- Телефон и email в amoCRM живут не в обычных полях, а в custom_fields_values: без правильных ID полей значения не запишутся. Справочники аккаунта смотри в `get_account`.
- `search` требует минимум 3 символа — на более коротком запросе не пытайся, попроси уточнить.
- Объединения дублей среди инструментов нет: если дубль уже создан, сообщи пользователю, что чистить надо в интерфейсе amoCRM.

## Формат ответа

```
## Поиск: «+79001234567»

### Найдено
| Тип | Название | ID | Ответственный |
|-----|----------|----|---------------|
| Контакт | Иванов Иван | 55120 | Петров |
| Сделка | Поставка Q3 | 88123 | Петров |

Дубль найден — новый контакт не создаю. Нужен новый? Скажите явно.

### Карточка 55120
Телефон: +79001234567 · Email: ivan@mail.ru
Компания: ООО Ромашка · Сделок: 3
```

## Примеры

```
/find-contact +79001234567
/find-contact Иванов
/find-contact заведи компанию ООО Ромашка
```
