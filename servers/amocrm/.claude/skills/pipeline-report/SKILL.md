# /pipeline-report — Состояние воронки

## Алгоритм

1. `list_pipelines` (без аргументов) — все воронки и их этапы. Отсюда берутся pipeline_id и status_id; без них цифры по этапам не собрать.
2. `list_leads` (pipeline_id, statuses, page, limit до 250, query, with) — сделки воронки. Пройди страницы, пока выдача не кончится.
3. Сгруппируй сделки по этапам: количество и сумма price на каждом.
4. Найди застрявшие: `list_events` (entity: leads, entity_id, type, page, limit до 100) — когда сделка последний раз двигалась. Нет событий давно = сделка стоит.
5. Открой проблемные карточки: `get_lead` (lead_id, with) — с вложенными контактами и причиной отказа.
6. Проверь, есть ли по ним задачи: `list_tasks` (entity_type: leads, entity_id, is_completed: false, responsible_user_id).
7. Если по сделкам нет ни одной активной задачи — это главный вывод отчёта: воронка без follow-up.
8. Имена ответственных и справочники аккаунта — `get_account`.

## Важно

- Считай сумму только по тем сделкам, которые реально выгрузил: `list_leads` отдаёт максимум 250 за страницу, оборванная выгрузка даёт заниженный итог. Скажи, сколько страниц прошёл.
- status_id уникален внутри воронки — не сравнивай этапы разных воронок по номеру.
- Ничего не меняй в этом скилле. Перенос сделки — `update_lead`, но только по отдельному явному запросу пользователя.

## Формат ответа

```
## Воронка «Продажи» (pipeline_id 3311)

Сделок: 148 · Сумма: 21 400 000 ₽ (выгружено 148 из 148)

| Этап | Сделок | Сумма |
|------|--------|-------|
| Первичный контакт | 61 | 6 100 000 ₽ |
| Переговоры | 44 | 9 800 000 ₽ |
| Счёт выставлен | 28 | 4 200 000 ₽ |

### Застрявшие (нет движения >14 дней)
1. Сделка 88123 «ООО Ромашка» — 850 000 ₽ — Переговоры — активных задач нет
```

## Примеры

```
/pipeline-report

```
