# /check-company — Проверка контрагента

## Алгоритм
1. Вызови `search_company` по ИНН/ОГРН
2. Вызови `get_company_brief` — краткий отчёт со сводкой рисков
3. Вызови `get_financial_statements` для финансовой аналитики (баланс, П&У)
4. Оцени надёжность по `get_bankruptcy_info` (банкротные производства) и `get_arbitration_cases` (арбитраж)
5. Покажи сводку с оценкой риска

## Формат ответа
```
## Контрагент: [название]
**ИНН**: ... | **Статус**: действующая
**Риск**: НИЗКИЙ / СРЕДНИЙ / ВЫСОКИЙ
**Финансы**: выручка, прибыль
```

## Примеры
```
/check-company 7707083893
```
