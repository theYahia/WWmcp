# /prepayment-check — Проверка перед переводом денег

## Алгоритм

1. Вызови `get_bankruptcy_info` с inn. Это первый и главный стоп-фактор: активное
   банкротное производство означает «не платить», остальное можно не читать.
2. Вызови `get_arbitration_cases` с inn. Смотри не только количество, но и роль:
   компания-ответчик по денежным искам — риск; истец — обычная хозяйственная активность.
3. Вызови `get_company_brief` с inn — краткий отчёт со сводкой рисков от Контур.Фокуса.
4. Если сделка требует допуска (строительство, медицина, перевозки, образование,
   алкоголь), вызови `get_licenses` с inn и проверь, что нужная лицензия действует
   на дату сделки, а не «была когда-то».
5. Вызови `get_company_details` с inn — убедись, что компания действующая, а не в
   ликвидации, и что подписант в ЕГРЮЛ совпадает с тем, кто подписывает договор.
6. Вынеси вердикт: ПЛАТИТЬ / ПЛАТИТЬ ПО ФАКТУ / НЕ ПЛАТИТЬ — с конкретными причинами.

## Формат ответа

```
## Проверка перед предоплатой: ООО «Ромашка», ИНН 7707083893

| Проверка | Результат |
|----------|-----------|
| Банкротство | производств нет |
| Арбитраж | 4 дела, ответчик по 3 на 12,4 млн ₽ |
| Статус в ЕГРЮЛ | действующая |
| Лицензии | СРО строительство — действует до 2027 |

**Вердикт**: ПЛАТИТЬ ПО ФАКТУ
**Причина**: 3 денежных иска к компании за 12 месяцев — предоплату не давать,
оплата по закрытым этапам.
```

## Важно

- Не подменяй вердикт вежливостью. Если есть банкротство — говори «не платить» прямо.
- Утверждай только то, что вернули инструменты. Нет данных по лицензиям — так и пиши
  «данных нет», а не «лицензий нет».
- ИНН юрлица 10 цифр, ИП — 12. Если пользователь дал ОГРН или название, сначала вызови
  `search_company` и получи ИНН.

## Примеры

```
/prepayment-check 7707083893
/prepayment-check ИНН 500100732259 — аванс 2 млн
```
