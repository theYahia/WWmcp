# AI-менеджер интернет-магазина: МойСклад + СДЭК + DaData через MCP

> Как связка трёх MCP-серверов заменяет 2-3 часа ежедневной рутины менеджера интернет-магазина.

---

## Проблема

Типичный день менеджера интернет-магазина:

| Задача | Время |
|--------|-------|
| Проверка остатков в МойСклад | 20 мин |
| Поиск и проверка реквизитов контрагентов | 15 мин |
| Оформление заказов покупателей | 40 мин |
| Расчёт стоимости доставки СДЭК | 20 мин |
| Создание накладных СДЭК | 30 мин |
| Переключение между вкладками, копипаст | 15 мин |
| **Итого** | **~2.5 часа** |

Это чистая рутина. Никакой экспертизы — только копирование данных из одной системы в другую. Каждый день. Каждый месяц. Каждый сотрудник.

---

## Решение

Три MCP-сервера, подключённых к AI-агенту (Claude Desktop, Cursor, или ваш собственный агент):

```
┌─────────────┐     ┌──────────────────┐     ┌─────────────┐
│   DaData    │     │    МойСклад      │     │    СДЭК     │
│  MCP Server │     │   MCP Server     │     │  MCP Server │
│             │     │                  │     │             │
│ validate_   │     │ search_products  │     │ calculate_  │
│ company     │     │ get_stock        │     │ tariff      │
│ suggest_    │     │ create_customer_ │     │ create_     │
│ address     │     │ order            │     │ order       │
│ clean_      │     │ get_counter-     │     │ get_offices │
│ address     │     │ parties          │     │ track_order │
└──────┬──────┘     └────────┬─────────┘     └──────┬──────┘
       │                     │                       │
       └─────────────────────┼───────────────────────┘
                             │
                    ┌────────▼────────┐
                    │   AI-агент      │
                    │  (Claude / LLM) │
                    └────────▲────────┘
                             │
                    ┌────────┴────────┐
                    │  Менеджер       │
                    │  "Создай заказ  │
                    │   для ООО       │

                    └─────────────────┘
```

Менеджер пишет одну фразу на русском языке — AI делает всё остальное.

## Полный сценарий: от запроса до накладной за 30 секунд

### Запрос менеджера

> «Создай заказ для ООО Ромашка на 50 шт Светильник LED-500, рассчитай доставку СДЭК до Новосибирска»

Одна фраза. Дальше AI-агент выполняет 6 шагов автоматически.

---

### Step 1: Проверка контрагента через DaData

**Tool:** `validate_company("ООО Ромашка")`
**Server:** DaData MCP

AI находит компанию по названию и получает:
- ИНН: `7712345678`
- ОГРН: `1177746123456`
- Юридический адрес: г. Москва, ул. Ленина, д. 10, оф. 5
- Статус: действующая
- Руководитель: Иванов И.И.

Зачем? Чтобы не ошибиться в реквизитах и не создать «мусорного» контрагента в МойСклад.

---

### Step 2: Проверка товара и остатков в МойСклад

**Tool:** `search_products("Светильник LED-500")`
**Server:** МойСклад MCP

Результат:
- UUID: `a1b2c3d4-...`
- Название: Светильник LED-500
- Цена: **1 200 ₽**
- Остаток на складе: **234 шт** (достаточно для заказа на 50 шт)
- Артикул: LED-500-W

AI проверяет: 50 ≤ 234 — хватает. Если бы не хватило — предупредил бы менеджера.

---

### Step 3: Поиск или создание контрагента в МойСклад

**Tool:** `get_counterparties(filter_inn: "7712345678")`
**Server:** МойСклад MCP

Два варианта:
- **Найден** → используем существующего контрагента
- **Не найден** → AI создаёт нового с реквизитами из DaData (ИНН, ОГРН, адрес)

Больше никакого ручного ввода реквизитов. Данные из DaData сразу попадают в МойСклад.

---

### Step 4: Расчёт доставки СДЭК

**Tool:** `calculate_tariff(from: "Москва", to: "Новосибирск", weight: 5000, length: 40, width: 30, height: 25)`
**Server:** СДЭК MCP

Результат:
- Тариф «Склад-склад»: **890 ₽**, срок 3-5 рабочих дней
- Тариф «Склад-дверь»: **1 240 ₽**, срок 4-6 рабочих дней

AI выбирает оптимальный тариф или спрашивает менеджера, если разница существенна.

---

### Step 5: Создание заказа покупателя в МойСклад

**Tool:** `create_customer_order(counterparty_id: "...", positions: [{product_id: "a1b2c3d4-...", quantity: 50, price: 1200}])`
**Server:** МойСклад MCP

Результат:
- Заказ **#12345** создан
- Сумма: 50 × 1 200 = **60 000 ₽**
- Доставка: **890 ₽**
- Итого: **60 890 ₽**
- Статус: «Новый»

---

### Step 6: Оформление накладной СДЭК

**Tool:** `create_order(recipient: {name: "ООО Ромашка", ...}, from: "Москва", to: "Новосибирск", packages: [...])`
**Server:** СДЭК MCP

Результат:
- Накладная СДЭК оформлена
- Трек-номер: `1234567890`
- Статус: «Принят»

---

### Итог: что получил менеджер

```
✅ Контрагент проверен через DaData — реквизиты верные
✅ Товар найден, остатков достаточно (234 шт)
✅ Заказ #12345 создан в МойСклад на 60 000 ₽
✅ Доставка СДЭК рассчитана: 890 ₽, 3-5 дней
✅ Накладная СДЭК оформлена, трек: 1234567890

Время выполнения: ~30 секунд
Время вручную: ~20 минут
```

## Какие tools используются

| Tool | MCP-сервер | Что делает |
|------|-----------|------------|
| `validate_company` | DaData | Проверка компании по названию → ИНН, ОГРН, адрес, статус |
| `suggest_address` | DaData | Подсказки по адресу для точной доставки |
| `clean_address` | DaData | Стандартизация адреса (индекс, ФИАС) |
| `search_products` | МойСклад | Поиск товаров по названию/артикулу |
| `get_stock` | МойСклад | Остатки на складах в реальном времени |
| `get_counterparties` | МойСклад | Поиск контрагентов по ИНН/названию |
| `create_customer_order` | МойСклад | Создание заказа покупателя с позициями |
| `calculate_tariff` | СДЭК | Расчёт стоимости и сроков доставки |
| `create_order` | СДЭК | Оформление накладной на отправку |
| `track_order` | СДЭК | Отслеживание статуса доставки |
| `get_offices` | СДЭК | Поиск ближайших ПВЗ для самовывоза |

## Конфигурация

### Claude Desktop / Cursor (`claude_desktop_config.json`)

```json
{
  "mcpServers": {
    "moysklad": {
      "command": "npx",
      "args": ["-y", "@theyahia/mcp-moysklad"],
      "env": {
        "MOYSKLAD_TOKEN": "ваш_токен_МойСклад"
      }
    },
    "cdek": {
      "command": "npx",
      "args": ["-y", "@theyahia/mcp-cdek"],
      "env": {
        "CDEK_CLIENT_ID": "ваш_client_id",
        "CDEK_CLIENT_SECRET": "ваш_client_secret"
      }
    },
    "dadata": {
      "command": "npx",
      "args": ["-y", "@theyahia/mcp-dadata"],
      "env": {
        "DADATA_API_KEY": "ваш_api_key",
        "DADATA_SECRET_KEY": "ваш_secret_key"
      }
    }
  }
}
```

Три строки конфига — и AI-агент получает доступ ко всем трём системам.

## ROI: экономика решения

### Расчёт экономии

| Параметр | Значение |
|----------|----------|
| Время рутины в день | 2-3 часа |
| Рабочих дней в месяц | 20 |
| Рутины в месяц | **40-60 часов** |
| Средняя ЗП менеджера (Москва) | 60 000 ₽ |
| Стоимость часа менеджера | ~375 ₽ |
| **Экономия в месяц** | **15 000 - 22 500 ₽** |

### Но это не всё

- **Скорость:** заказ оформляется за 30 секунд вместо 20 минут
- **Точность:** DaData исключает ошибки в реквизитах (неправильный ИНН = проблемы с бухгалтерией)
- **Масштаб:** AI обрабатывает 10-й и 100-й заказ с одинаковой скоростью
- **Доступность:** работает 24/7, не болеет, не увольняется

### Стоимость решения

| Компонент | Стоимость |
|-----------|----------|
| MCP-серверы (@theyahia) | Бесплатно (open source) |
| API МойСклад | Входит в тариф МойСклад |
| API СДЭК | Бесплатно (оплата за отправки) |
| API DaData | От 0 ₽ (бесплатный тариф — 10 000 запросов/день) |
| Claude API / Claude Pro | ~$20/мес |
| **Итого** | **~$20/мес** |

**Экономия ~25 000 ₽/мес при затратах ~1 500 ₽/мес.** ROI > 15x.

## Что дальше

Этот сценарий — лишь один из возможных. Связка MCP-серверов позволяет автоматизировать:

- **Закупки:** мониторинг остатков → автоматическое создание заказов поставщикам
- **Отчётность:** `get_profit_report` + `get_rates` (ЦБ РФ) = отчёт с конвертацией валют
- **Массовые обновления:** `update_prices` по всему каталогу на основе курсов валют
- **Клиентский сервис:** отслеживание доставок по трек-номерам через `track_order`

Подключайте серверы — пусть рутиной занимается AI.
