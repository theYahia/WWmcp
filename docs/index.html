Emerging Markets

7 servers. Versions and descriptions come from servers/*/package.json.

Countries named in the package descriptions: Turkey, Egypt, Saudi Arabia, Ethiopia, Bangladesh, Senegal, Argentina, Brazil, Mexico, Uruguay, Chile, Colombia, Peru, Ecuador, Venezuela. Orange Money also covers 10 Francophone West and Central African markets its description does not name individually.

Setup
{
  "mcpServers": {
    "salla": {
      "command": "npx",
      "args": ["-y", "@theyahia/salla-mcp"],
      "env": { "SALLA_ACCESS_TOKEN": "your-token" }
    }
  }
}
