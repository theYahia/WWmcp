# NeuralDeep MCP — Стратегия выхода в РФ AI-комьюнити

## Цель

Засветиться как разработчик в российском AI-комьюнити, набить статус, быть полезным. Строим серию MCP-серверов для российских сервисов под брендом **neuraldeep.ru**.

---

## Процесс публикации

```
Пишешь MCP-сервер (TypeScript, ~200-400 строк)
        ↓
Публикуешь на npm (@neuraldeep/dadata-mcp)
        ↓
Листишь в MCP-каталогах (glama.ai, smithery.ai, mcp.so)
        ↓
Репо на GitHub с README на русском + английском
        ↓
Пост на Habr / dev.to / Telegram-каналы
        ↓
Разработчики подключают к Claude / Cursor / Windsurf
        ↓
GitHub stars → npm downloads → узнаваемость
```

## Почему это сработает именно сейчас

- MCP — **горячая тема** прямо сейчас, все про неё пишут
- Российские сервисы **не покрыты** (0.05% от 20 000+ глобальных MCP)
- Ты будешь **первым** — кто первый листит, тот получает трафик
- Каждый следующий MCP усиливает бренд neuraldeep
- Рынок GenAI в России вырос **в 5 раз** до 58 млрд руб в 2025
- **71% компаний** уже используют генеративный ИИ
- **850 000+ селлеров** на маркетплейсах нуждаются в автоматизации

## Роадмап: 3 недели до бренда

### Неделя 1: DaData MCP
- **Что:** suggest_address, find_company, validate_phone, validate_email, geocode_address
- **Публикация:** npm + GitHub + glama.ai + smithery.ai
- **Контент:** Пост в Telegram AI-каналы, README с gif-демо
- **Почему первый:** must-have зависимость, простой API, 9/10 документация

### Неделя 2: ЮKassa Payments MCP
- **Что:** create_payment, get_status, create_refund, generate_receipt
- **Публикация:** npm + GitHub + каталоги
- **Контент:** Статья на Habr "Как я делаю MCP для российского стека"
- **Почему второй:** финтех привлекает внимание, sandbox для тестов

### Неделя 3: hh.ru Recruiter MCP или СДЭК Logistics MCP
- **Что:** search_vacancies, search_resumes, get_salary_statistics / calculate_delivery, track_shipment
- **Публикация:** npm + GitHub + каталоги
- **Контент:** Уже есть бренд, комьюнити растёт, кросс-промо предыдущих пакетов
