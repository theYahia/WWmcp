# Агентные скиллы для российского стека: исследование рынка и ТОП-15 идей для neuraldeep.ru

Глобальная экосистема MCP насчитывает **20 000+ серверов**, но российские сервисы представлены менее чем в 0,05% из них — около 8–10 реализаций, преимущественно для 1С, Битрикс24, Яндекс.Поиск и Telegram. При этом рынок GenAI в России вырос **в 5 раз** до ₽58 млрд в 2025 году, **71% компаний** уже используют генеративный ИИ, а **850 000+ селлеров** на маркетплейсах нуждаются в автоматизации. Ни один из крупнейших российских маркетплейсов (Ozon, Яндекс.Маркет), платёжных систем (ЮKassa), логистических сервисов (СДЭК), HR-платформ (hh.ru) и ERP-систем (МойСклад) не имеет качественного MCP-сервера. Это создаёт беспрецедентную возможность для neuraldeep.ru стать стандартом агентных интеграций с российскими сервисами.

## ТОП-15 идей для скиллов по матрице приоритизации

### 1. Ozon Seller MCP

**Сервис/API:** Ozon Seller API (REST, 278+ методов, Postman-коллекции)

**Ключевые инструменты:**
- `get_product_analytics` — аналитика по товарам (продажи, конверсии, позиции)
- `manage_prices_and_stocks` — массовое обновление цен и остатков по SKU
- `process_orders` — обработка и отгрузка заказов FBO/FBS
- `generate_product_cards` — создание/обновление карточек товаров с AI-оптимизацией
- `respond_to_customer_chats` — автоответы на вопросы покупателей
- `get_financial_reports` — выгрузка финансовых отчётов и расчёт unit-экономики
- `manage_promotions` — управление участием в акциях и промо

**Целевая аудитория:** Селлеры Ozon (сотни тысяч), агентства управления маркетплейсами, интеграторы

**Уровень уникальности:** 10/10 — при наличии TypeScript SDK (278 методов) и PHP-библиотек ни одного MCP-сервера не существует. Ozon — второй по величине маркетплейс России с GMV **$50B+**.

**Бизнес-ценность:** 10/10 — селлеры тратят часы ежедневно на ручное управление; автоматизация цен, остатков и отгрузок экономит десятки тысяч рублей в месяц

**Сложность реализации:** MEDIUM — API хорошо документирован (8/10), но широкий набор методов требует продуманной архитектуры

**Потенциал хайпа:** 9/10 — маркетплейсовая тема горячая, 250+ селлеров подключились к аналитическому боту за 3 дня

**Killer demo:** *«Скажи агенту 'подними цены на 5% на все товары с маржинальностью ниже 20%' — и он обновит 500 SKU за секунды через Ozon API»*

### 2. DaData Enrichment MCP

**Сервис/API:** DaData API (REST, документация 9/10)

**Ключевые инструменты:**
- `suggest_address` — подсказки и стандартизация адресов (ФИАС/КЛАДР)
- `find_company` — поиск компании по ИНН/ОГРН/названию с полными данными из ЕГРЮЛ
- `validate_phone` — валидация и определение оператора по номеру телефона
- `validate_email` — проверка email на существование и одноразовость
- `geocode_address` — геокодирование и обратное геокодирование
- `standardize_name` — стандартизация ФИО (склонение, пол, род)
- `get_delivery_info` — маппинг адреса на зоны доставки СДЭК/Boxberry/DPD

**Целевая аудитория:** Все разработчики на российском рынке — от e-commerce до HR и логистики

**Уровень уникальности:** 8/10 — существует только через Composio (platform-dependent), standalone MCP отсутствует

**Бизнес-ценность:** 9/10 — DaData используется практически в каждом российском B2B-проекте для валидации данных; незаменимый инфраструктурный сервис

**Сложность реализации:** LOW — API отлично документирован, простая авторизация через токен, чистый REST

**Потенциал хайпа:** 7/10 — инфраструктурный скилл без яркого визуала, но «must-have» для любого агента, работающего с данными о клиентах

**Killer demo:** *«Агент получает 'ООО Рога' — и за секунду возвращает полные реквизиты, адрес, ФИО директора, ОКВЭД и финансовые данные»*

## Быстрые победы: можно сделать за выходные

Эти скиллы сочетают **высокую уникальность** с **низкой сложностью** реализации — минимум эндпоинтов, простая авторизация, отличная документация.

**1. DaData Enrichment MCP** — самый быстрый старт. API DaData использует простой Token-based auth, все эндпоинты — чистый POST/GET JSON. За один день можно покрыть подсказки адресов, поиск компании по ИНН и валидацию телефонов. Это **must-have** для любого агента, работающего с российскими данными, и мгновенно становится зависимостью для десятков других скиллов.

**2. hh.ru Recruiter MCP** — HeadHunter имеет OpenAPI spec на GitHub, документация отлично структурирована. Базовый набор (search_vacancies, search_resumes, get_salary_statistics) реализуется за день. HR-автоматизация — горячая тема при дефиците кадров (вакансии в IT упали **на 20% YoY** — компании ищут альтернативы найму).

**3. ЮKassa Payments MCP** — API v3 имеет sandbox, SDK на Python/Node.js, документация с примерами для каждого метода. Три базовых тула (create_payment, get_status, create_refund) — это 2–3 часа работы. Финтех-скилл привлекает внимание и сразу полезен.

**4. СДЭК Logistics MCP** — тестовые credentials доступны без контракта, публичные методы (расчёт тарифов, список ПВЗ) работают «из коробки». Калькулятор доставки + трекинг — за один вечер.

**5. МойСклад Inventory MCP** — JSON API 1.2 признан одним из лучших российских API по качеству документации. Basic Auth, RESTful, вложенные expand-запросы. Базовый CRUD товаров + отчёты — за выходные.

## Стратегические ставки: долгосрочно но мощно

**1. Marketplace Multi-Analytics MCP (WB + Ozon + Яндекс.Маркет)** — это потенциальный **стандарт индустрии**. Сегодня 850 000+ селлеров на одном только Маяке, большинство продают на 2–3 площадках. Коммерческие аналитические сервисы (MPSTATS, MarketGuru) берут от ₽3 000/мес за базовую аналитику. Open-source агент, агрегирующий данные трёх маркетплейсов с единым интерфейсом, может стать дефолтным инструментом для российского e-commerce. Сложность высокая (три API, маппинг SKU, разные форматы), но потенциал — создание нового стандарта для мультиплатформенных селлеров. Монетизация через premium-функции и интеграции с МойСклад/1С.

**2. Yandex Ads Stack MCP (Директ + Метрика + Вебмастер)** — после ухода Google Ads из России Яндекс.Директ стал **единственной** крупной рекламной платформой. Связка с Метрикой даёт полный цикл: управление кампаниями → анализ конверсий → оптимизация. Коммерческий MCP уже продаётся (habab.ru), что валидирует спрос. Open-source версия с полным покрытием API может стать обязательным инструментом для каждого рекламного агентства в России. По данным Ingate, **33% маркетологов** хотят AI-оптимизацию рекламных кампаний.

**3. 1С Universal Bridge MCP** — хотя для 1С уже существует **8+ MCP-проектов** (лидер — vladimir-kharin/1c_mcp с **274★**), ни один не предлагает универсальный production-ready мост «1С ↔ любой AI-агент». Учитывая, что **1С стоит в каждой** российской компании, а 55% бизнесов автоматизируют бухгалтерию, стандартизированный MCP-коннектор к 1С с поддержкой основных конфигураций (Бухгалтерия, УТ, ERP, ЗУП) — это потенциальный «PostgreSQL MCP» для российского рынка.

## Неочевидные жемчужины

**1. Почта России + СДЭК + Boxberry Unified Logistics MCP** — логистика кажется скучной, но **каждый** интернет-магазин работает с 2–3 службами доставки одновременно. Единый агент, который сравнивает тарифы, выбирает оптимальный способ, создаёт заказ и отслеживает посылку через один интерфейс, решает реальную ежедневную боль. Почта России и Boxberry имеют API, но ими почти никто не интегрируется через AI-агентов. Особенно ценно в связке с маркетплейсовыми скиллами для DBS-заказов.

**2. Roistat + Calltouch End-to-End Analytics MCP** — **35% маркетологов** хотят AI для lead scoring и attribution. Roistat и Calltouch — ведущие российские платформы сквозной аналитики (от клика до продажи), оба имеют API, но **ноль** MCP-серверов. Агент, который может ответить «какой канал принёс самых прибыльных клиентов в марте?» или «какие ключевые слова в Директе приводят звонки но не продажи?» — золотой инструмент для CMO. Нишевая аудитория, но готовая платить.

**3. Честный Знак (Honest Sign) Compliance MCP** — система обязательной маркировки товаров уникальна для России и **не имеет мировых аналогов**. Список маркируемых категорий непрерывно расширяется (одежда, обувь, молочка, парфюмерия, БАДы, пиво...). Производители и ритейлеры обязаны отчитываться через API Честного Знака под угрозой штрафов. MCP-скилл для проверки кодов, формирования отчётов и мониторинга статусов — это compliance-инструмент, за который бизнес готов платить. Сложность высокая (УКЭП), но и барьер входа для конкурентов соответственно высок.

## Ключевые выводы для стратегии neuraldeep.ru

Российский рынок агентных скиллов находится в начальной стадии формирования. При **20 000+ MCP-серверов** глобально, российские сервисы покрыты менее чем на **0,05%**. Только **2 официальных** MCP-сервера выпущены российскими компаниями (Яндекс Поиск и Битрикс24), что подтверждает: вендоры признают формат MCP, но рынок ещё не насыщен.

Самый сильный органический сигнал спроса — экосистема **1С** (8+ проектов, 274★ на лидирующем репо). Это показывает, что российские разработчики активно строят MCP-интеграции снизу вверх. Второй по силе сигнал — **маркетплейсы**: Telegram-бот аналитики WB/Ozon набрал 250+ пользователей за 3 дня, а на Kwork автоматизация WB продаётся от 8 000₽.

Оптимальная стратегия для neuraldeep.ru: начать с **4–5 быстрых побед** (DaData, hh.ru, ЮKassa, СДЭК, МойСклад) за 2–3 недели, чтобы набрать начальную GitHub-аудиторию и доказать ценность платформы. Параллельно запустить разработку **стратегических ставок** (Ozon, WB Pro, Yandex Ads Stack), которые обеспечат долгосрочный рост. Marketplace Multi-Analytics MCP — потенциальный «killer feature», способный привлечь сотни тысяч селлеров и стать де-факто стандартом для российского e-commerce.
