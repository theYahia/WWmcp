# Deep Research Prompt — Дистрибуция MCP-серверов в РФ и СНГ

## Контекст

Мы — NeuralDeep (@metarebalance на npm). Разрабатываем MCP-серверы (Model Context Protocol) для российских сервисов. Первый продукт — `@metarebalance/dadata-mcp` (31 инструмент, полное покрытие API DaData.ru). Опубликован на npm и GitHub (github.com/theYahia/dadata-mcp).

Целевая аудитория: русскоязычные разработчики, интеграторы, DevOps, AI-инженеры, предприниматели, которые используют Claude, Cursor, VS Code, Windsurf и другие AI-инструменты с поддержкой MCP.

## Задача исследования

Провести исчерпывающий анализ **всех каналов дистрибуции, продвижения и монетизации** MCP-серверов для российского и СНГ рынка. Для каждого канала нужны конкретные действия, ссылки, контакты, форматы контента.

## Формат ответа

Для каждого блока:
1. **Конкретные действия** (не абстрактные советы, а "зайди сюда, нажми это, напиши то")
2. **Ссылки** (URL каждого ресурса)
3. **Приоритет** (критично / важно / nice-to-have)
4. **Трудозатраты** (минуты/часы)
5. **Ожидаемый эффект** (охват, конверсия)

Не давай общих советов типа "продвигайте в соцсетях". Нужны конкретные каналы, конкретные форматы, конкретные шаги.
