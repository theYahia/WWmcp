# Стратегическая карта MCP-серверов для российского рынка

**Российский рынок API представляет колоссальную возможность для neuraldeep.ru: из ~70 исследованных сервисов менее 10 имеют MCP-серверы, а глобальная экосистема MCP уже превысила 10 000 серверов.** Первый продукт @neuraldeep/dadata-mcp занял абсолютно правильную нишу — data enrichment — и теперь задача состоит в системном захвате смежных категорий. Исследование покрывает 70+ российских API/SaaS-сервисов, выявляет конкурентов, скорирует каждый сервис по 7 метрикам и предлагает конкретную дорожную карту из 3 волн разработки.

Рынок AI-агентов в России растёт взрывным темпом: **520 млрд ₽ в 2025 году (+20% YoY)**, при этом 60%+ крупных компаний заинтересованы во внедрении AI-агентов. MCP становится стандартом де-факто: Anthropic передал протокол в Linux Foundation, его поддержали OpenAI, Google, Microsoft, AWS. Yandex уже интегрировал MCP в AI Studio, а Сбер выпустил серию собственных MCP-серверов через GigaChain. Однако для российских бизнес-сервисов практически нет качественных MCP-серверов — это окно возможностей, которое закроется в ближайшие 6–12 месяцев.

## Детали по ключевым API: документация, аудитория, реферальные программы

### Финтех и платежи — золотая жила для MCP

**ЮKassa** занимает **40% рынка онлайн-платежей** России с **106 000+ подключённых сайтов**. API документация на https://yookassa.ru/developers/api — RESTful JSON, HTTP Basic Auth, OpenAPI-спецификация. Sandbox доступен сразу после регистрации, даже без договора. Партнёрская программа (https://promo.yookassa.ru/agents) выплатила партнёрам **97,8 млн ₽** только в 2023 году — это ~10%+ от комиссий привлечённых клиентов. Ключевые операции: платежи, возвраты, чеки (54-ФЗ), рекурренты, выплаты, split-платежи, Safe Deal. **MCP-сервер отсутствует**, есть только один Claude-навык (2 установки).

**МойСклад** — **3 млн+ зарегистрированных аккаунтов**, API на https://dev.moysklad.ru/doc/api/remap/1.2/ — JSON API 1.2 с Basic Auth. Разработчики называют это «**лучшим API среди ~44 протестированных**». Документация на GitHub (open-source), rate limit 100 req/5 сек. Партнёрская программа (https://partners.moysklad.ru/): до 50% скидки + разработчики маркетплейса получают **75% дохода** от продаж решений.

**ЦБ РФ** — универсальный сервис для всего финтеха. XML-фиды на https://www.cbr.ru/development/sxml/, неофициальное JSON-зеркало на https://www.cbr-xml-daily.ru/daily_json.js. Полностью бесплатный, без авторизации. Данные: курсы валют, ключевая ставка, цены драгметаллов, справочник БИК. Rate limit зеркала: 1 req/sec, 30/min, 10K/day. Сложность реализации MCP — **один вечер**.

### Маркетплейсы — гигантская аудитория с максимальной болью

**Ozon Seller API** (https://docs.ozon.ru/api/seller/) покрывает всё: товары, цены, остатки, FBO/FBS заказы, аналитику, рекламу. Sandbox: cb-api.ozonru.me. **~450 000 активных продавцов** на Ozon (2024). Боли продавцов: комиссии менялись **6 раз** во второй половине 2025, суммарные расходы достигают **40–60% от выручки**. Навязывание автоакций, сложный расчёт unit-экономики. **26,6% продавцов** торгуют одновременно на 2–3 площадках — огромный спрос на мультимаркетплейс-автоматизацию.

**Wildberries** (https://dev.wildberries.ru/) — **~500 000 активных продавцов**, sandbox доступен. Однако **уже существуют 2+ MCP-сервера** (dmitriipolushin и lyohadunker26). Конкуренция снижает приоритет.

**Яндекс.Маркет** (https://yandex.ru/dev/market/partner-api/doc/ru/) — OpenAPI-спецификация на GitHub, растущая платформа. MCP-сервер **отсутствует**. Хороший кандидат для «Marketplace Seller» мета-MCP.

### CRM и автоматизация бизнеса — лучшие реферальные программы

**amoCRM** — **~150 000+ компаний**, REST API v4 с OAuth 2.0. Партнёры получают **до 50%** от платежей клиентов. Разработчики виджетов зарабатывают **25–35%** комиссии. MCP-сервер **полностью отсутствует** — при этом это второй по популярности CRM в России.

**Битрикс24** — **15 млн+ организаций**, но уже имеет **официальный MCP** (mcp.bitrix24.ru) и 2+ community-сервера. Партнёрская программа (https://partners24.1c-bitrix.ru/) даёт **20–50% от лицензий**. Строить конкурирующий MCP нецелесообразно — лучше искать интеграционные возможности.

**hh.ru** — крупнейший job-сайт России, **50 млн+ резюме**. API на https://github.com/hhru/api — OpenAPI-спецификация, отличная документация. MCP-сервер **отсутствует**. Высокая виральность: «MCP для рекрутинга» — тема с гарантированным хайпом на Хабре.

### Яндекс-экосистема — стратегическое значение

**Яндекс.Директ** (https://yandex.ru/dev/direct/) — **500 000+ рекламодателей**, при этом **худший DX** среди популярных Яндекс API: микровалюта, XML-ошибки, запутанная сосуществование v4/v5, долгое подтверждение приложений. Документация на 3/5. Sandbox есть (api-sandbox.direct.yandex.com). MCP-обёртка здесь дала бы **максимальное облегчение боли разработчиков**. MCP-сервер **отсутствует**.

**Яндекс.Вебмастер** (https://yandex.ru/dev/webmaster/) — документация **худшая** в Яндекс-экосистеме (2/5): устаревшие примеры, путаница HTTP-методов, ограничение на 1000 хостов. MCP-сервер **отсутствует**, есть только навык от Polyakov (13 установок).

**YandexGPT** — растущий спрос, но уже частично покрыт через Yandex Cloud MCP. Standalone-сервер мог бы быть полезен для тех, кто не использует Yandex Cloud целиком.

## Тренды 2025–2026 и незанятые ниши

### Что растёт быстрее всего

Российский облачный рынок достиг **416,5 млрд ₽** в 2025 (+32,8% YoY). Сегмент GenAI вырос в **5 раз** за год до 58 млрд ₽. **36% организаций** уже используют AI в ограниченном или полном масштабе (против 20% в 2024). Россия — **4-я в мире** по числу AI-агентных стартапов. Ключевые катализаторы: импортозамещение (уход западного ПО), государственные инвестиции **15,7 млрд ₽** в AI на 2024–2026, обязательная маркировка товаров (Честный ЗНАК), цифровизация ЖКХ.

### Самые перспективные незанятые ниши

**ГИС ЖКХ** — **50 000+ управляющих компаний** обязаны отчитываться через систему, но SOAP API требует ГОСТ-криптографии и крипто-туннелей. Ни одного современного REST-обёртки или MCP-сервера не существует. Разработка крайне сложна, но ценность колоссальна.

**Честный ЗНАК / True API** — обязательная маркировка для **миллионов бизнесов** (табак, молочка, обувь, текстиль, вода, пиво, парфюмерия). Документация «самая запутанная и неинформативная» по отзывам разработчиков — версии обновляются еженедельно. MCP-обёртка упростила бы жизнь огромному числу предпринимателей, но реализация сложна (УКЭП, частые изменения).

**Мультимаркетплейс-автоматизация** — 26,6% продавцов торгуют на 2–3 площадках одновременно. SelSup и PinAll пытаются решить эту задачу, но MCP-подход (единый интерфейс для Ozon + WB + YM через AI-агента) не реализован.

**OFD-аналитика** — данные онлайн-касс используются только для фискальной отчётности, хотя API ОФД позволяют строить глубокую бизнес-аналитику. Практически никто не интегрирует эти данные с CRM/ERP автоматически.

### Композитные мета-MCP: стоит ли строить

Идея «Russian Business Stack» (DaData + ЮKassa + МойСклад + СДЭК + amoCRM в одном MCP) — **привлекательна, но преждевременна**. Практики на Хабре советуют: «Начинайте постепенно — не пытайтесь создать MCP для всего сразу. Идите итеративно.» Проблемы мега-MCP: обслуживание 5 API одновременно, разные механизмы авторизации, перегрузка LLM инструментами (tool overload снижает точность выбора). **Рекомендация: строить отдельные MCP-серверы, которые можно подключать к AI-агенту одновременно** — это архитектурно чище, проще в поддержке, и пользователь сам выбирает набор. Композитный «Marketplace Seller MCP» (Ozon + WB + YM) имеет смысл как premium-продукт на этапе зрелости, когда все три отдельных MCP уже стабильны.

## Антипаттерны: чего делать не стоит

- **НЕ строить MCP для Битрикс24** — уже есть официальный сервер (mcp.bitrix24.ru) и 2+ community-версии. Конкуренция с вендором нецелесообразна.
- **НЕ строить MCP для Telegram Bot API** — 10+ серверов разного качества уже существуют, рынок перенасыщен.
- **НЕ начинать с ГИС ЖКХ, ЕГАИС или ГИИС ДМДК** — требуют УКЭП, крипто-туннели, ГОСТ-криптографию. Месяцы на реализацию при неочевидной аудитории MCP (управляющие компании не используют AI-агентов).
- **НЕ строить мета-MCP до завершения отдельных серверов** — сначала надёжные автономные серверы, потом композиция.
- **НЕ пытаться покрыть Wildberries** — уже есть 2 MCP-сервера + навык. Лучше вложить время в Ozon (0 конкуренции, сопоставимая аудитория).
- **НЕ строить для СБП напрямую** — нет standalone API, только через банки-посредники.
- **НЕ инвестировать в Sber Business API ранние итерации** — сложность 4/5, OAuth + цифровые подписи, долгая интеграция.
