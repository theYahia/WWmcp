# Deep Research — MCP-серверы для узбекистанских API

## Контекст

Мы — @theyahia (npm org). Создали 47 MCP-серверов для российских API (Model Context Protocol). Все опубликованы на npm и GitHub. Расширяемся на рынок Узбекистана — **второй приоритет международной экспансии** после Казахстана. По предварительным данным: MCP-серверов для узбекских API **не существует вообще**. ~40 000 разработчиков, растущий tech-сектор. Примечательно: существует **PayTechUZ** — unified payment library для Payme+Click+Uzum+Paynet с активным Telegram-сообществом.

Нам нужно полное исследование рынка, чтобы создать MCP-серверы для ключевых узбекистанских сервисов и занять нишу первыми.

## Формат ответа

Для каждого сервиса:
1. **Название и URL** — точная ссылка на API документацию
2. **Статус API** — публичный / по заявке / закрытый / нет API
3. **Авторизация** — тип (API Key, OAuth, Basic Auth, без авторизации)
4. **Ключевые endpoints** — 5-10 самых полезных
5. **Rate limits и sandbox** — есть ли тестовая среда
6. **Существующие SDK/пакеты** — npm, PyPI, GitHub (со ссылками)
7. **Конкуренция** — есть ли уже MCP/интеграции
8. **Приоритет для нас** — высокий/средний/низкий с обоснованием
9. **Оценка трудозатрат** — сколько дней на создание MCP
10. **Синергия** — как связать с существующими российскими MCP (например, 1С, СДЭК)

Не давай абстрактных советов. Нужны конкретные URL, конкретные endpoints, конкретные шаги.
