# Deep Research — MCP-серверы для казахстанских API

## Контекст

Мы — @theyahia (npm org). Создали 47 MCP-серверов для российских API (Model Context Protocol). Все опубликованы на npm и GitHub. Теперь расширяемся на рынок Казахстана — **первый приоритет международной экспансии**. По предварительным данным: MCP-серверов для казахских API **не существует вообще**. ~60 000 разработчиков, русскоязычная среда, минимальная адаптация.

Нам нужно полное исследование рынка, чтобы создать MCP-серверы для ключевых казахстанских сервисов и занять нишу первыми.

## Формат ответа

Для каждого сервиса:
1. **Название и URL** — точная ссылка на API документацию
2. **Статус API** — публичный / по заявке / закрытый / нет API
3. **Авторизация** — тип (API Key, OAuth, Basic Auth, без авторизации)
4. **Ключевые endpoints** — 5-10 самых полезных
5. **Rate limits и sandbox** — есть ли тестовая среда
6. **Существующие SDK/пакеты** — npm, PyPI, GitHub
7. **Конкуренция** — есть ли уже MCP/интеграции
8. **Приоритет для нас** — высокий/средний/низкий с обоснованием
9. **Оценка трудозатрат** — сколько дней на создание MCP

Не давай абстрактных советов. Нужны конкретные URL, конкретные endpoints, конкретные шаги.
