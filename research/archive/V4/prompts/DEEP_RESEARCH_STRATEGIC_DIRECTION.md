## Конкурентная ситуация

### В России
- **DaData** запустила свой официальный MCP-сервер (https://dadata.ru/mcp/) — 4 tools vs наших 31
- **Wildberries** имеет 3-4 независимых MCP от других разработчиков
- Для остальных 45 сервисов MCP **не существует** — мы первые
- **Окно возможностей 3-6 месяцев** — крупные компании начнут выпускать свои

### В Казахстане и Узбекистане
- **Ноль** MCP-серверов для любых API этих стран
- Рынки растут: КЗ = "Год цифровизации и AI 2026", УЗ = обязательный безнал с 01.04.2026

### Глобально
- MCP-экосистема взрывной рост: mcp.so = 19K+ серверов, Smithery = 7K+
- Anthropic продвигает MCP как стандарт: Official Registry, MCP Directory
- OpenAI, Google, Microsoft поддержали MCP-протокол
- Для "региональных API" (не глобальных SaaS) ниша почти пустая

## Стратегические опции (из мастер-плана)

### Опция A: "Ширина" — подать все 47 на все площадки + контент-маркетинг
- Цель: максимальный охват, попадание в GitHub Trending, npm visibility
- Риск: размазать усилия, 47 серверов среднего качества не впечатлят
- Effort: 2-3 недели на площадки + 2-3 недели на контент

### Опция B: "Глубина" — взять 5 топ-серверов и довести до production-grade
- Цель: тесты, Streamable HTTP, идеальная документация, real user feedback
- Риск: потерять first-mover advantage на остальных 42
- Effort: 3-4 недели на 5 серверов

### Опция C: "Монетизация первой" — открыть р/с, зарегистрироваться в рефках, контент
- Цель: доход с первого месяца (реферальные ссылки в README)
- Риск: без пользователей реферальные ссылки не работают
- Effort: 1-2 дня на р/с, 3-5 дней на рефки, потом контент

### Опция D: "CIS-экспансия" — сразу делать КЗ и УЗ серверы
- Цель: занять пустые рынки, бренд "the MCP guy for post-Soviet APIs"
- Риск: распылиться, ещё не закрепились даже в России
- Effort: 28 дней КЗ + 31 день УЗ

### Опция E: "Вирусный запуск" — координированный launch (Habr + HN + Reddit + PH в один день)
- Цель: попасть в GitHub Trending, набрать 100-500 stars за 48 часов
- Риск: если контент не зацепит — потрачено время впустую
- Effort: 7-10 дней подготовки, 1 день запуска

### Опция F: "E-commerce стек" — сфокусироваться на единой истории Ozon+WB+YM+МойСклад
- Цель: конкретный use case для конкретной аудитории (продавцы маркетплейсов)
- Риск: MCP не подходит для real-time синхронизации (это выяснено)
