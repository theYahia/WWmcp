Initial release v1.0.0. MCP server for bKash Tokenized Checkout (Bangladesh's #1 mobile financial service, 70M+ users). 8 tools covering payments, refunds, and recurring agreements. Custom `BkashAuthStrategy` implements bKash's 3-step token grant flow with auto-refresh. Sandbox + production endpoint switching via `BKASH_SANDBOX` env. Built on `@theyahia/mcp-core`.
