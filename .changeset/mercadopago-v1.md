Initial release v1.0.0. MCP server for MercadoPago covering 10 tools across payments, refunds, checkout preferences, and merchant orders. Multi-country support (AR/BR/MX/UY/CL/CO/PE/EC/VE) via single Bearer access token. Built on `@theyahia/mcp-core` with stdio + Streamable HTTP transports.
