Initial release v1.0.0. MCP server for Fawaterak (Egypt's payment aggregator covering Fawry, cards, wallets, Meeza). 8 tools spanning invoices, payment methods, refunds, and merchant balance. Bearer auth via `FAWATERAK_API_KEY`. Sandbox vs production switching via `FAWATERAK_SANDBOX` env. Built on `@theyahia/mcp-core`.
