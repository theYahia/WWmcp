Initial release v1.0.0. MCP server for Chapa (Ethiopia's modern payment gateway). 8 tools covering transaction initialization, verification, transfers, bank listing, and account balance. Bearer auth via single `CHAPA_SECRET_KEY` env var (test/live via key prefix). Built on `@theyahia/mcp-core`.
